# Week 7 – Hugging Face Pipelines

## Project Description
This project demonstrates Natural Language Processing (NLP) using Hugging Face models and prompt engineering.

## Tasks Completed
1. Sentiment Analysis
2. Text Summarization
3. English-to-French Translation
4. Question Answering
5. Pipeline result comparison
6. One-shot prompting
7. Few-shot prompting
8. Role-based prompting
9. Reasoning prompt comparison
10. Three reusable prompt templates
11. Prompt evaluation

## Tools Used
- Python
- Pandas
- Hugging Face Transformers
- PyTorch
- Jupyter Notebook
- Visual Studio Code

## Project Structure
- `dataset/` – Stores input data and CSV results
- `notebook/Week7_HuggingFace_Pipelines.ipynb` – Contains the experiments
- `pipelines.py` – Creates the input CSV file
- `requirements.txt` – Lists required Python libraries

## How to Run
1. Open the project folder in VS Code.
2. Activate the virtual environment.
3. Install the packages using `pip install -r requirements.txt`.
4. Open the notebook and select the `.venv` kernel.
5. Run the notebook cells from top to bottom.

## Output
The CSV files store the NLP outputs, prompt responses, and evaluation results.
